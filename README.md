# Red Team — Password Security Lab

## Objective
Conduct offline testing on sample data to compare fast hash algorithms (such as MD5/SHA1) against bcrypt and Argon2id.

## Safety Scope
- Use only the Kali VM and synthetic data generated by the team.
- Analyze only the hash files provided in the lab; do not attempt to log in to any actual services.
- Do not use real-world leaked data or personal information.

## Data
- `../../wordlists/` — sample password lists.
- `../../hashes/` — sample MD5, SHA1, bcrypt, and Argon2id hashes.
- `../../results/` — test results and execution times.

## Testing Methodology
Use John the Ripper to perform offline testing of the sample hashes against the lab's wordlists. Record the algorithm, configuration, execution time, and results in `../../results/`.

## Results
To be updated following the completion of the tests and the comparative analysis of the algorithms.

## Ethical Commitment
All testing is conducted exclusively within the authorized lab environment using synthetic data. No attacks will be directed at systems or accounts outside of this defined scope.
